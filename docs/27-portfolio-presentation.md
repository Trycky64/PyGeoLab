# 27 — Présentation portfolio

## Pourquoi PyGeoLab est intéressant

PyGeoLab démontre des compétences dans plusieurs domaines simultanément :

- Python avancé ;
- POO ;
- architecture ;
- GUI desktop ;
- mathématiques ;
- géométrie computationnelle ;
- parsing ;
- graphes ;
- optimisation ;
- tests ;
- packaging.

## Démo idéale

1. création de trois points ;

4. déplacement d'un sommet ;
5. recalcul instantané ;
6. création d'une fonction ;
