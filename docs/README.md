# PyGeoLab — Documentation du projet

PyGeoLab est une application de géométrie dynamique et de visualisation mathématique développée entièrement en Python.

L'objectif du projet est de construire un logiciel interactif permettant de créer, manipuler et relier des objets géométriques, tracer des fonctions mathématiques, calculer des propriétés dynamiques et sauvegarder des constructions complètes.

Cette documentation décrit l'architecture cible, les choix techniques, les conventions, les fonctionnalités, les algorithmes, les tests et la roadmap du projet.

## Objectifs principaux

- Construire un logiciel de géométrie dynamique moderne en Python.
- Permettre la manipulation directe des objets à la souris.
- Recalculer automatiquement les objets dépendants.
- Supporter les principales constructions de géométrie plane.
- Tracer et analyser des fonctions mathématiques.
- Proposer une interface graphique claire et fluide.
- Fournir une architecture propre, modulaire et testable.
- Servir de projet portfolio démontrant des compétences solides en Python.
