# 13 — Import et export

## Export PNG

Options :

- zone visible ;
- résolution ;
- fond transparent ou opaque.

## Export SVG

Le SVG est important car la géométrie se prête naturellement au vectoriel.

Exporter :

- segments ;
- droites clippées ;
- cercles ;
- polygones ;
- fonctions ;
- textes.

## Export de données

Fonction future :

- CSV des points ;
- JSON simplifié.

## Import

Initialement :

- fichiers `.pgl`.

Extensions futures :

- CSV de points ;
- expressions texte ;
- formats tiers limités.

## Compatibilité GeoGebra

Pas d'objectif de compatibilité complète.

Une compatibilité partielle pourra être étudiée ultérieurement.
