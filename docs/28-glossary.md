# 28 — Glossaire

## Canvas

Zone graphique principale.

## Viewport

Transformation déterminant quelle partie du monde mathématique est visible.

## World coordinates

Coordonnées mathématiques indépendantes des pixels.

## Screen coordinates

Coordonnées en pixels.

## GeoObject

Objet métier géométrique ou mathématique dans le document.

## Free object

Objet directement contrôlé par l'utilisateur.

## Dependent object

Objet dont l'état est calculé depuis d'autres objets.

## Dependency graph

Graphe décrivant les relations entre objets.

## Dirty

État indiquant qu'un objet doit être recalculé.

## Hit-testing

Recherche de l'objet situé sous ou près du curseur.

## Snapping

Alignement automatique sur une cible pertinente.

## AST

Abstract Syntax Tree, représentation structurée d'une expression.

## Serialization

Transformation du document en données sauvegardables.

## Deserialization

Reconstruction du document depuis un fichier.
